# โครงการฝึกอบรม หลักสูตรการสื่อสารและการบริหารทีมงานเพื่อผลสัมฤทธิ์

**ผู้เขียน:** พชรพงศ์ พงษ์โพธิ์ไชย (5614480003)  
**วิชา:** HRD 6103 การวางแผน การพัฒนา และการจัดโครงการการพัฒนาทรัพยากรมนุษย์  
**อาจารย์:** รองศาสตราจารย์ ดร.โฆษิต อินทวงศ์  
**สถาบัน:** คณะพัฒนาทรัพยากรมนุษย์ มหาวิทยาลัยรามคำแหง  
**วันที่ส่ง:** 19 เมษายน 2557 (2014)

เผยแพร่เปิดสาธารณะเพื่อให้นักพัฒนาองค์กร ผูฝึกอบรม และผูสนใจนำไปออกแบบหลักสูตร 3 วัน

## จุดสำคัญ

หลักสูตร 3 วัน 18 ชั่วโมง สำหรับหัวหน้างาน พนักงานทุกระดับ และผูจัดการ ไม่เกิน 50 คนต่อรุ่น เน้นการเรียนรู้แบบผูใหญ่

### หัวข้อ
1. การสื่อสารด้วยใจ (6 ชั่วโมง)
2. ทีมเวิร์ค…ทีมในฝัน (6 ชั่วโมง)
3. ปรับเปลี่ยนความคิดการทำงานร่วมกัน
4. ทักษะที่จำเป็นในการทำงาน

### วิธีอบรม
บรรยาย สาธิต ระดมสมอง เกม กลุ่มสัมพันธ์ บทบาทสมมติ และแลกเปลี่ยนประสบการณ์

### งบประมาณ
วิทยากรและผูช่วย 40,000 บาท วัสดุ 5,000 บาท อาหารว่าง 18,000 บาท อาหารกลางวัน 27,000 บาท รายการรวม 90,000 บาท (ต้นฉบับรวมเป็น 85,000 บาท)

### การประเมิน
ก่อน–หลังอบรม ความพึงพอใจ และติดตามทักษะหลัง 3 เดือน ผูเข้าไม่น้อยกว่า 80% และผ่านการทดสอบได้รับวุฒิบัตร
